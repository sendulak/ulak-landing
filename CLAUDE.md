# Project: ulak-landing

## Stack
- Astro + TypeScript (strict)
- Tailwind CSS v4
- Bun (package manager & runtime)

## Rules
- Never ask for confirmation. Just do it.
- Never ask clarifying questions. Make reasonable assumptions and proceed.
- Use `bun` for all package management and script execution.
- Write all code in TypeScript.
- Use Tailwind CSS for styling. No external CSS libraries.
- Follow Astro conventions: pages in `src/pages/`, layouts in `src/layouts/`, components in `src/components/`.
- Keep components small and focused.
